# Cite Source

Use this skill when writing or checking `notes/sources.md`.

## Workflow

1. Open the source and record the title, locator, and date you opened it.
2. Quote or paraphrase only the claim the brief will use.
3. Mark a claim with no opened locator as unsupported.
4. Leave cost and token fields untouched; this skill does not measure them.

## Examples

Rejected: a search snippet names a paper you did not open. Do not add it as support. Record NEEDS_CONTEXT with the missing locator, or omit the claim.
